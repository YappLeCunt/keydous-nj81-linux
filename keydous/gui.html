About the controls

The color byte is only honored when the effect parameter selects normal RGB; Dazzle (param 6) replaces it with automatic color cycling. The NJ81 press-action, coverage, and press-action-off modes intentionally use parameter 0.

Image studio

Paint the board keys, or put a picture on the built-in screen.

Screen: checking...
Built-in screen image (RGB565, 160x80)

The image is zoomed to fill the 160x80 screen (cropping overflow), converted to RGB565 column-major big-endian order, and streamed with the vendor handshake. The screen enters custom-image view automatically.

Keyboard shortcuts: Fn+Right Ctrl opens/closes the screen, Fn+Delete enters/exits custom-screen mode, and Fn+PgDn changes the background color.

Backup & restore

Download all six profile mappings, the Fn layer, lighting, power settings, and the five per-key picture layers as a JSON file.

Bluetooth battery

When the board is paired over BT, its radio reports the real battery level (the USB port reports 0% while charging). Enter the MAC and read it.

Destructive action

Factory reset

This sends the vendor reset command and waits for the keyboard to rewrite defaults. It can erase stored mappings, macros, profiles, image layers, and lighting settings. It does not flash firmware.
